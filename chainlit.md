## 🆕 First time? Register from the login form

Registration uses a single line in the **Username** field, made of
four pieces separated by `|` (the pipe character):

```
username | email@domain.com | Full Name | Institution
```

Then type your desired password in the **Password** field and click
**Sign in**.

### Copy this template and fill in your own details

```
your_username|you@example.com|Your Name|Your School
```

### Worked example

| Field      | What to type                                          |
| ---------- | ----------------------------------------------------- |
| Username   | `john_doe\|john@med.edu\|John Doe\|Stanford Medical` |
| Password   | `securepass123`                                       |

> If you see "incorrect username or password" right after registering,
> the format is most likely off — double-check that you used `|` (pipe)
> as the separator and that all four pieces are present.
